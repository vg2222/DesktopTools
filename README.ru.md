## ✨ Один набор инструментов вместо множества приложений

**От быстрого снимка экрана до подробной демонстрации.** Снимите область экрана, отметьте важную деталь или запишите окно вместе со своим голосом. Переходите от показа к объяснению, не собирая для этого целую коллекцию отдельных приложений.

**Удерживайте внимание аудитории.** Рисуйте поверх экрана, используйте лазерную указку, подсвечивайте нужную область или придерживайтесь плана с помощью телесуфлёра и таймеров.

**И заодно решайте небольшие задачи.** Распознавайте текст на снимке экрана, переводите между английским и русским локально, держите заметки под рукой, создавайте QR-коды или обрезайте изображения перед отправкой.

## 🔒 Локальная обработка по умолчанию

Без учётной записи, телеметрии и облачной обработки ваших данных. Снимки экрана, заметки, распознавание текста, перевод между английским и русским и удаление фона обрабатываются на вашем компьютере.

Вы сами выбираете, куда сохранять изображения и записи. Автоматическая проверка обновлений обращается к GitHub за сведениями о новых версиях, но не загружает туда ваши медиафайлы или заметки. Изменить интервал проверки или отключить её можно в разделе **Настройки → Обновления**.

Элементы управления записью и рисованием, уведомления, плавающие заметки и телесуфлёр по умолчанию скрыты от поддерживаемых способов захвата. Рисунки и эффекты для аудитории остаются видимыми. Настройки отдельных инструментов находятся в разделе **Настройки → Конфиденциальность**. Исключение из захвата зависит от приложения, через которое идёт запись или трансляция, поэтому перед началом проверьте изображение, которое получают зрители.

## ⚙️ Настройте под себя

1. Установите DesktopTools или распакуйте портативный ZIP-архив, затем откройте приложение.
2. При первом запуске выберите оформление, инструменты и параметры демонстрации экрана.
3. Закрепите любимые инструменты и настройте сочетания клавиш.

После закрытия главного окна DesktopTools продолжает работать в области уведомлений. Чтобы открыть приложение снова, нажмите его значок в трее; чтобы завершить работу, выберите **Выход** в меню значка.

| Действие | Сочетание клавиш по умолчанию |
| --- | --- |
| Рисовать / взаимодействовать | Ctrl + Alt + D |
| Снять область экрана | Ctrl + Alt + S |
| Показать / скрыть элементы рисования | Ctrl + Alt + H |
| Лазерная указка | Ctrl + Alt + L |
| Прожектор | Ctrl + Alt + O |
| Стоп-кадр | Ctrl + Alt + F |

На странице **Сочетания клавиш** перечислены все привязки функций. Стандартные сочетания включены, дополнительные по умолчанию отключены. У каждого сочетания есть собственный переключатель.

Раздел **Диагностика** проверяет системные компоненты, языки распознавания текста Windows и конфликты сочетаний. Поиск в **Настройках** открывает параметры конкретного инструмента.

## 💡 Несколько подробностей

Для записи экрана, локального перевода и удаления фона нужен Microsoft Visual C++ x64 Redistributable. Запись и монтаж видео используют Windows Media Foundation. Частота записи до 144 кадров в секунду является целевой; фактическая производительность зависит от источника, кодировщика и оборудования. Ограничения захвата и актуальный объём тестирования описаны в разделе [совместимости](docs/compatibility.md). Установщик проверяет наличие пакета Visual C++ и при необходимости предлагает страницу загрузки Microsoft.

Приложение поддерживает **английский, русский, немецкий, французский и испанский языки**, а также светлое, тёмное и системное оформление. Языки интерфейса не связаны с поддерживаемой сейчас парой перевода — английским и русским.

```powershell
./scripts/fetch-translation-models.ps1
./scripts/build.ps1
```
