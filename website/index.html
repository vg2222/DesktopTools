Questions? Answered.

Something else? Open an issue on GitHub

Is DesktopTools really free?

Yes. Every feature is free, with no trial, no paid tier and no account. The project is supported only by voluntary donations.

Can I use it at work?

Yes. DesktopTools is open source under the MIT license, which allows personal and commercial use.

Which systems does it run on?

Windows 11 on x64 PCs. The installer brings everything else it needs, except the Microsoft Visual C++ runtime, which some features require.

Does it upload my screenshots?

No. Captures, recordings, notes and text recognition stay on your PC. The app goes online only to check for updates and news, and for downloads you start yourself.

Does it use AI?

Only when you ask. Transcripts, the OCR pack, high-quality background removal, face suggestions and extra translation languages use optional models. Each one is downloaded from its publisher only after you accept its licence, and runs on your PC.

Why does Windows show a warning when I install it?

The installer isn’t code-signed yet, so SmartScreen may warn you. Each release publishes SHA-256 checksums so you can check the file you downloaded.
