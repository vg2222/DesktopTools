# Optional model inventory

This inventory describes the catalog in the local AI update. Optional model files are not bundled. Downloads happen only at the user's request after licence consent, directly from the publisher's URL. The embedded catalogs pin every file's revision, byte size and SHA-256. Full licence texts below are exact copies of the texts the app shows; no model weights were downloaded for this documentation review. For measured behavior and limitations, see [Optional AI models](../ai-models.md).

Training-data terms are separate from model licences; disclosure is not a claim that those datasets are unrestricted. The owner still needs to decide whether the disclosure is sufficient.
