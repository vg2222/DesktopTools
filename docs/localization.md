# Interface translations

English is the source language. `src/DesktopTools/Localization/*.<language>.json` maps English UI strings to translations and is embedded with `WithCulture=false`. Supported languages are English plus Russian (`ru`), German (`de`), French (`fr`), Spanish (`es`), Ukrainian (`uk`), Simplified Chinese (`zh`), Portuguese (`pt`), Japanese (`ja`), Polish (`pl`), Turkish (`tr`) and Italian (`it`). Keep the same key sets in every language and use UTF-8. A new language needs a code and native name in `L.Languages`/`L.LanguageNames`, a flag in `src/DesktopTools/Assets/Flags` and its mapping in the installer's `LanguageFlag`, plus one catalog file per feature file. Duplicate keys across feature catalogs must have identical translations.

Use `L.T` only at display boundaries. Use `L.F` for interpolated messages; preserve every indexed placeholder, alignment and numeric format. Preserve file-dialog filter patterns after `|`. Never translate saved action IDs, profile names, file paths, note/script text, OCR output or shortcut strings. Choice controls translate their display template while retaining original selected values; pass `false` for user-defined lists.

New preferences use the Windows UI language when it is supported; otherwise they use English. A saved language always takes precedence. Changing the language saves the preference and restarts DesktopTools automatically. Unknown saved values recover to English. Profile switching preserves the language setting. System dialogs and native Windows messages are controlled by the operating system.

Run the core tests for catalog parity, placeholders, file filters, Unicode, persistence and stable settings. Run the integration harness with `--localization-only` on Windows for every supported language, both themes, all main pages and utility renders. Review the resulting `artifacts/integration/locale-*.png` screenshots. This mode does not inject input into other applications. The Ukrainian, Chinese, Portuguese, Japanese, Polish, Turkish and Italian catalogs were written without a native-speaker review and are marked as such in the release notes; corrections are welcome. Sidebar labels in languages with long words are kept to one short word because they must not wrap.
