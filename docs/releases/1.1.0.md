# DesktopTools 1.1.0

This update makes DesktopTools easier to use in your Windows language and clarifies recording and update controls. Existing notes, settings and recordings are preserved during an update.

## What's new

- On a fresh install, setup and the app start in the supported language closest to your Windows display language. Setup includes a language picker; changing the app language later restarts it to apply the selection throughout the interface.
- Setup, first-run screens and additional interface messages have expanded translations for German, Spanish, French and Russian.
- The recorder places its source and preview controls together and keeps start, pause, stop, timer and status in a dedicated control area.
- The Updates page shows installed and available versions more clearly. Automatic checks can now run every 15 or 30 minutes, or every 2 or 3 hours, alongside the existing intervals.
- Installer text, recording dependency guidance and other controls have clearer spacing and focus behavior.

## Downloads

- `DesktopTools-1.1.0-win-x64-setup.exe` — recommended per-user installer.
- `DesktopTools-1.1.0-win-x64-portable.zip` — self-contained portable build.

Windows 11 x64 is required. Screen recording also requires Microsoft Visual C++ x64 Redistributable and Windows Media Foundation; setup offers the official Microsoft download page if the Visual C++ runtime is missing. The binaries are unsigned, so Windows SmartScreen may prompt. Compare your download with `SHA256SUMS.txt` on this release.

Capture exclusion depends on the receiving application's capture method. Mixed-DPI hardware, long recordings and real-device audio synchronization still need broader testing; see [compatibility notes](../compatibility.md).
