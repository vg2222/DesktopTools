# DesktopTools 1.2.7

This update adds step-by-step screenshot guides, recording markers and local screenshot privacy review, and improves the recorder, notes, video editor, and app appearance.

- Build a numbered guide from recent captures or a screenshot folder. Open one image in the annotation editor before adding it, or edit an existing step; crop, draw, add text, and cover private details without changing the source. The picker has a resizable two-column layout; drag steps to reorder them, choose one to six steps per row, and export a high-resolution PNG with a light, dark, or custom background.
- Notes open as ordinary windows by default. An Always on top option in Notes settings controls both the notes library and floating notes. Note-to-window attachment is no longer available; existing notes remain saved.
- Add markers during a recording, then find them on the video editor timeline. Hover a marker to see its number and time, or select it to seek there.
- The video editor has a resizable settings pane, audio volume and export quality controls, preview playback speed, and full-resolution PNG frame export. Playback speed affects the preview only.
- The larger recorder setup gives the source and audio controls more room. Hardware encoding uses the timestamps of arriving frames instead of padding high-FPS output with repeated frames. The requested FPS remains a target, limited by display refresh, capture throughput, and encoder performance.
- The dark app surface defaults to `#060606`. Feature windows follow the selected default or custom app background. Opening the video editor no longer crashes while arranging its header.
- Text tools offer 20 offline translation languages. English–Russian remains bundled; download other checksum-verified packs once, then translate without a connection. Compatible Windows languages appear first. Pairs without a direct model translate through English. OCR reads installed Windows recognizers, matches regional language tags, and can refresh after language-pack changes.
- Auto Redact Screenshot suggests areas containing possible email addresses, phone numbers, IP addresses, local paths, keys/tokens and context-labelled identifiers using local Windows OCR. Use **Check screenshot** in the screenshot editor, image tools or guide editor, then **Hide all found** in one undoable action or select individual numbered areas. Keep areas visible or draw and resize covers manually. The compact panel uses DesktopTools controls and keeps results visible in short windows. Solid covers are the default; blur and pixelation provide weaker hiding. Undo and Original/Edited comparison preserve the source image.
- Sensitive-data OCR enlarges bounded tiles to read small text without changing source coordinates. When a non-English recognizer is selected, installed English OCR also checks email addresses and machine data; intersecting results are merged. This improves lists where OCR previously dropped domain punctuation in small addresses. Recognizer accuracy still varies with image quality.
- Privacy review handles slashed-zero OCR substitutions in IP addresses and keys, and recognizes Russian **API-ключ:** labels and labelled passwords. The manual-cover, detection-options and drawing-options buttons have clearer theme-aware outlines.
- Screenshot privacy review now keeps complete split logins, phone numbers, paths and labelled identifiers inside their suggested covers. An additional reading improves tiny text, and installed English/app-language OCR checks mixed labels. The generated 25-value sample covers emails, phones, IPv4/IPv6, paths, keys/tokens, passwords, logins, account IDs and serials at both tested font sizes.
- Enable **Check screenshots before copying or saving** in Capture settings to review new screenshots before output. This is off by default. Pending captures do not enter the clipboard or capture history; closing the review cancels output. Unresolved suggestions, failed scans and subsequent edits require review, another scan or an explicit skip. Only a successful Copy or Save publishes the reviewed image. OCR and pattern matching may miss sensitive data, so inspect the result before sharing. No screenshot or recognized text is uploaded or stored as an OCR transcript.

- Privacy review now recognizes two-column tables without colons, including **User ID**, **Пароль** and numbered nickname labels. Aligned neighbouring rows link labels to their values even when Windows OCR separates the columns or value fragments into different lines. Suggested covers include the full value; unrelated distant columns and ordinary password advice remain excluded in the tested cases.

- Lists of standalone nickname-like identifiers are also suggested without labels, including mixed-case numeric names and underscore handles. Adjacent and overlapping OCR fragments retain complete bounds across different font sizes. Two aligned rows corroborate a list; recognized labels and a separate table-label column are excluded. Small monospace telephone readings also handle a measured `e`-for-zero substitution, while date validation remains active.

- Screenshot privacy review now suggests complex password-like values inside prose and lists, rather than requiring a `Password:` field. Nearby password wording and a strong next-row continuation can recover a wrapped value as separate covers. IPv4 matching accepts sentence-ending punctuation and measured OCR digit substitutions; prefixed keys tolerate a measured `5k` reading of `sk`. Detached password punctuation retains the surrounding value bounds. Ordinary URLs and password-policy advice are excluded by regression tests, although suggestions remain approximate.

- For very small text, privacy OCR also checks narrow rows at three-times size, with a bounded tile/word budget and cancellation. This recovers words discarded by Windows OCR on a mixed-size page. It does not recover every damaged glyph: unreadable octets are not silently accepted as IP addresses. Review the highlighted regions and add manual covers for missed data.

- Privacy review now recovers prefixed keys wrapped across rows and checks small inline gaps where Windows OCR omitted a value. Covers stay on the relevant rows, and a telephone beside an IP remains detectable. The latest mixed-font prose sample covers all 22 values across 25 physical pieces under English and Russian OCR; the observed ordinary-word false positives are excluded. Very small or damaged text can still require manual covers.

- Full-monitor privacy checks now skip empty horizontal margins during small-text recovery instead of exhausting the supplemental OCR budget. Trailing words missed by the first reading remain eligible for recovery. Wrapped keys/passwords use local row geometry, and dotted password-like values are recognized. OCR remains approximate; review the suggested covers.
- The screenshot editor initially opens centered at 75% of the monitor's working-area width and height. You can resize it normally; the screenshot resolution stays unchanged.

- Full-screen privacy review now follows wrapped keys within their text column even when browser navigation appears between the rows. It also keeps a wrapped password's numeric tail inside a separate suggested cover. Cross-line recovery excludes ordinary URL fragments and limits nearby-row search work.

## Desktop Automation preview

- Build workflows with a searchable action library, recording, templates, undo and separate run settings. Choose windows and shortcuts directly; move or duplicate complete loops and conditional branches. Test individual actions and import/export local JSON workflows.
- Run manually, by shortcut, at intervals, when a window appears, daily at a local time, or when DesktopTools starts. Automatic triggers require enabling and saving, and run while DesktopTools is open. Imports are disarmed.
- New actions wait for a window or pixel color, set/paste clipboard text, and minimize, maximize or restore windows. Set the delay between actions; stop with Esc. After opening an app, add Focus window before typing or clicking.
- Existing automation files upgrade to schema 2 without losing workflows; earlier preview binaries cannot edit the newer schema. Scrolling Screenshot is not included.
## Downloads

- `DesktopTools-1.2.7-win-x64-setup.exe` — per-user installer.
- `DesktopTools-1.2.7-win-x64-portable.zip` — self-contained portable build.
- `SHA256SUMS.txt` — checksums for both files.

Requires Windows 11 x64. Screen recording, offline translation and image background removal require the Microsoft Visual C++ x64 Redistributable; recording and video editing also depend on Windows Media Foundation. The installer is unsigned, so Windows SmartScreen may show a warning. Verify `SHA256SUMS.txt` against the downloaded files. Recording and remote-sharing behavior can vary by hardware and other apps; use the five-second test clip and check sharing visibility before relying on them.
