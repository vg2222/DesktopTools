# DesktopTools 1.2.2

This patch smooths update notifications and fixes installer language switching.

- Notifications animate when they appear and resize smoothly when their message or actions change. Update progress uses the DesktopTools accent color and rounded corners.
- The installer and uninstaller can switch languages while open without restarting or losing the selected uninstall data option. The language chooser has clearer spacing and offline flag icons.
- An older installer now offers **Install older version** under **Advanced options**, with an explicit warning. Notes and settings are retained, although settings from a newer app may not work in the older version.
- Update rollback retries brief file locks while restoring the previous installation. Persistent locks still produce an error rather than replacing files unsafely.

## Downloads

- `DesktopTools-1.2.2-win-x64-setup.exe` — recommended per-user installer.
- `DesktopTools-1.2.2-win-x64-portable.zip` — self-contained portable build.

Windows 11 x64 is required. Screen recording also requires Microsoft Visual C++ x64 Redistributable and Windows Media Foundation. These binaries are unsigned; Windows SmartScreen may prompt. Verify downloads using `SHA256SUMS.txt`.
