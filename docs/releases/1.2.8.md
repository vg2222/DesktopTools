# DesktopTools 1.2.8

This update makes recordings smoother and sharper, reads text from pictures far more accurately, and adds a searchable screenshot library, GIF and WebP export, seven more interface languages and a native Windows ARM64 build.

## Text from pictures

- **Scan screen text** (and **Extract text** in the screenshot editor and in Image tools) opens a text view: the picture is dimmed, every recognized word stays bright inside a thin outline, and you select text straight on the picture like in a PDF. Drag over words, double-click a word, triple-click a line, press Ctrl+A, copy with Ctrl+C or the **Copy selection** / **Copy all** buttons. A rainbow rim and a sweeping light run while the picture is being read.
- Web addresses, e-mail addresses and phone numbers are underlined; Ctrl+click opens them. F2 on a word fixes a misread word for copying and translating without touching the picture. **Translate** sends the selection to the local translator. In the editors, **Back to editing** returns to the tools.
- Reading is much more accurate. Several readings of the picture (plain, grey and a contrast map, at the magnification that suits the text size) are combined word by word, judged by the Windows spelling dictionary for the language and by how many readings agree, and a word that is one letter-mixup from a real word is put right ("Claün offer" becomes "Claim offer"). In a test of about 1,600 phrases drawn in 15 fonts, 10 sizes and 10 colour schemes with ClearType, exact phrases rose from 70% with plain Windows OCR to 93%; text of 12 pixels and larger is read right 95-100% of the time. Text of 9-10 pixels, especially thin serif and Courier fonts, is still often wrong. Reading a 2240 × 1600 screenshot takes about three seconds.
- The Windows spelling dictionaries are used locally; only the languages installed in Windows have one, and other languages are read as before.

## Screenshot editor and Image tools

- Draw, Style and Hide data are tabs with icons and readable labels in the dark theme. The presentation style (background, rounded corners, shadow, window bar) is shown live on the drawing canvas, and drawing is smooth on large pictures. **Check screenshot** shows an animated rim while the picture is analysed. The Original/Edited button changes its icon.
- **Hide private data** no longer blocks Copy and Save after you edit the picture or cancel a check. The "Continue without checking" button remains only when you chose to review every capture before output.
- Image tools has an **Annotate** tab with the same drawing and Hide data tools, a title-bar Original/Edited button with the same icon change, and **Extract text** with **Back to editing**. Leaving Annotate adds the drawing to the picture as one undoable step.

## Recording and export

- Recordings keep the screen's rate and a bitrate that fits the picture, so 144 Hz displays no longer produce soft, stuttering video. Window recording is limited by Windows to about 48 frames per second.
- The video editor exports **GIF** and **animated WebP** with a size estimate before saving.

## Library, languages and packaging

- An opt-in **Screenshot library** (Home, Capture tools) keeps recent captures searchable by the text in them and can be cleared at any time.
- Ukrainian, Chinese, Portuguese, Japanese, Polish, Turkish and Italian join English, Russian, German, French and Spanish, in the app and in the installer. The translations are machine-written and not yet reviewed by native speakers.
- Settings can be exported and imported as one archive. **Diagnostics** can copy a bug report with your user name, computer name, paths, e-mail and IP addresses replaced.
- A native Windows ARM64 build is available (not yet tested on ARM hardware). Package files for winget, Scoop and Chocolatey are included in the repository.

## Reliability

- Copying text and pictures to the clipboard no longer fails with "Unable to open clipboard" when a clipboard manager or Windows clipboard history is using it at the same moment. DesktopTools now opens the clipboard only while writing, waits patiently, and says which program was in the way if it still cannot copy.
