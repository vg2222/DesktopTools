# DesktopTools 1.2.6

This release improves region capture and screen recording, adds screenshot guides, and makes editing and setup easier to use.

- Smart Region Capture suggests an area under the pointer. Click the highlight to capture it, or drag to select any custom area. A fresh frozen screen suggests windows from its saved geometry; live selection can also suggest accessible panels, images, and video areas. An older frozen drawing frame keeps manual selection. The feature can be turned off in Region capture settings; selection stays local and offline.
- Notes open as ordinary windows by default. The Notes feature setting can keep both the notes library and floating notes above other windows; existing notes stay available after updates.
- Step-by-step guides can use recent DesktopTools captures or images from a resizable, two-column screenshot picker. Drag to reorder steps, choose one to six steps per row and a light, dark or custom export background, then save a high-resolution numbered PNG without changing the originals.
- The screen recorder shows microphone and system-audio activity, offers a five-second test clip, checks destination free space, and reports the frame rate stored in a completed MP4. Device activity and file metadata do not guarantee audible audio or distinct captured frames; play the test clip to verify.
- The recorder setup is larger, and high-FPS recordings use timestamps from arriving frames instead of padding hardware output with repeated frames. The target remains a ceiling; source refresh, Windows capture and encoder performance still limit distinct FPS.
- Recording markers now appear on the editor timeline with marker-number/time hover details and quick seeking. The settings pane has a drag handle, with audio-volume and export-quality controls, adjustable preview playback speed, and full-resolution PNG frame export.
- Screenshot and image tools clearly switch between the original and edited copy. The video editor can return to its latest rendered preview after showing the original. Crop instructions are clearer across editors.
- Recorder audio meters now use the app's rounded, accent-colored track. The recorder HUD falls back to the primary display if Windows does not report a cursor position.
- The recorder setup window no longer stays above other apps, and its bottom Start/Pause/Stop panel remains one row high; the five-second test action is beside the audio settings.
- A News page shows repository announcements with an unread indicator and optional notifications. A security notice can highlight a verified stable update without installing or restarting automatically; the existing confirmation remains required.
- Pin window now changes only windows DesktopTools pinned itself. Already-on-top windows retain their own state, and a queued shortcut message from an older binding cannot trigger Pin window after shortcut settings change.
- Image tools and the video editor open maximized for a larger workspace. Both have maximize/restore controls, and standard resizable tool windows can be minimized.
- Setup has a clearer task summary, places Advanced options in the left rail when extra choices are available, and supports resizing from its lower-right corner. Install, update, repair, uninstall, and data-preservation choices remain available.
- The News page places refresh in its header and aligns announcement details with the cards, leaving more room for the announcements themselves.
- The dark app surface uses `#060606` by default, and opening the video editor no longer crashes while arranging its header.
- Feature windows now follow the selected default or custom app background instead of keeping a gray glass tint.

## Downloads

- `DesktopTools-1.2.6-win-x64-setup.exe` — per-user installer.
- `DesktopTools-1.2.6-win-x64-portable.zip` — self-contained portable build.
- `SHA256SUMS.txt` — checksums for both files.

Requires Windows 11 x64. Screen recording, offline translation and image background removal require the Microsoft Visual C++ x64 Redistributable; recording and video editing also depend on Windows Media Foundation. The installer is unsigned, so Windows SmartScreen may show a warning. Verify `SHA256SUMS.txt` against the downloaded files. Recording and remote-sharing behavior can vary by hardware and other apps; use the five-second test clip and check sharing visibility before relying on them.
