# DesktopTools 1.2.6 — preview

This preview improves the screen recorder, adds notes that can follow another application's window, and makes editor previews easier to understand. It is for local testing and is not a published GitHub release.

- Floating notes can attach to an open window, follow its movement, hide while it is minimized, and reappear when it returns. Attachments are saved with notes and can be removed from the notes list.
- The screen recorder shows microphone and system-audio activity, offers a five-second test clip, checks destination free space, and reports the frame rate stored in a completed MP4. Device activity and file metadata do not guarantee audible audio or distinct captured frames; play the test clip to verify.
- Screenshot and image tools clearly switch between the original and edited copy. The video editor can return to its latest rendered preview after showing the original. Crop instructions are clearer across editors.
- Recorder audio meters now use the app's rounded, accent-colored track. The recorder HUD falls back to the primary display if Windows does not report a cursor position.
- The recorder setup window no longer stays above other apps, and its bottom Start/Pause/Stop panel remains one row high; the five-second test action is beside the audio settings.
- A News page shows repository announcements with an unread indicator and optional notifications. A security notice can highlight a verified stable update without installing or restarting automatically; the existing confirmation remains required.

## Local downloads

- `DesktopTools-1.2.6-win-x64-setup.exe` — per-user installer.
- `DesktopTools-1.2.6-win-x64-portable.zip` — self-contained portable build.
- `SHA256SUMS.txt` — checksums for both files.

Requires Windows 11 x64. Screen recording, offline translation and image background removal require the Microsoft Visual C++ x64 Redistributable; recording and video editing also depend on Windows Media Foundation. This preview is unsigned. Interactive recording, audio-device, multi-monitor note-following and remote-sharing checks are still pending.
