# DesktopTools 1.2.1

This patch improves background update reliability when Windows briefly holds an installation file open after DesktopTools exits.

- Setup retries the application-folder swap for a short, bounded period when Windows reports a sharing or access lock. If the lock persists, the update leaves the previous installation in place and reports a clearer error.
- The installer and portable build otherwise contain the 1.2.0 recorder, image-editor, and tray improvements.

## Downloads

- `DesktopTools-1.2.1-win-x64-setup.exe` — recommended per-user installer.
- `DesktopTools-1.2.1-win-x64-portable.zip` — self-contained portable build.

Windows 11 x64 is required. Screen recording also requires Microsoft Visual C++ x64 Redistributable and Windows Media Foundation. These binaries are unsigned; Windows SmartScreen may prompt. Verify downloads using `SHA256SUMS.txt`.
