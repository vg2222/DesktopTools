# DesktopTools 1.1.1

This patch fixes update retries and makes update notifications easier to use.

- A retry no longer replaces an installer file that Windows still has open. Each verified setup download gets its own staging location.
- Clicking an update notification now shows the restart and unsaved-work confirmation inside that notification. Confirming starts the download and setup handoff without opening a separate app dialog.
- Portable copies wait until DesktopTools has closed before opening setup.
- Notifications remain visible while the pointer is over their window, including when WPF does not report mouse-over for a non-activating notification.
- Failed scheduled update checks stay silent and preserve the previous status. Manual checks still report errors.

## Downloads

- `DesktopTools-1.1.1-win-x64-setup.exe` — recommended per-user installer.
- `DesktopTools-1.1.1-win-x64-portable.zip` — self-contained portable build.

Windows 11 x64 is required. Screen recording also requires Microsoft Visual C++ x64 Redistributable and Windows Media Foundation. These binaries are unsigned; Windows SmartScreen may prompt. Verify downloads using `SHA256SUMS.txt`.
