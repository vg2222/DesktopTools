# DesktopTools 1.2.0

This release makes the recorder and tray controls easier to use and removes an unnecessary image-editor setup choice.

- The recorder now has a clearer source preview with display, window, and region cues. Recording quality, target FPS, and hardware acceleration sit together, with the timer and controls in a compact panel below them.
- The image editor opens its guide directly. Its annotation toolbar uses a consistent position instead of asking new users to choose between A and B.
- Right-clicking the tray icon opens a DesktopTools-styled menu with shortcuts to the main window, recorder, pinned screenshot, and quick actions.
- The installer language picker has a clearer layout.

## Downloads

- `DesktopTools-1.2.0-win-x64-setup.exe` — recommended per-user installer.
- `DesktopTools-1.2.0-win-x64-portable.zip` — self-contained portable build.

Windows 11 x64 is required. Screen recording also requires Microsoft Visual C++ x64 Redistributable and Windows Media Foundation. These binaries are unsigned; Windows SmartScreen may prompt. Verify downloads using `SHA256SUMS.txt`.
