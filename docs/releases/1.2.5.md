# DesktopTools 1.2.5

This release makes tools easier to find and configure. Each feature now opens its own settings page, Settings search finds tools by name, category, description or shortcut, and Diagnostics shows native components, OCR languages and shortcut registration with links to relevant fixes.

- Screen recording, offline translation and image background removal explain when the Microsoft Visual C++ x64 runtime is missing. Other tools remain available.
- Home, Help, Shortcuts and Settings search now have clearer empty states, aligned text fields and accessible clear actions. Shortcut tabs and retry actions have updated icons, with smoother content transitions.
- The update notification uses a concise **Update** action. It still asks for confirmation before downloading and restarting, and preserves saved notes and settings.
- The installer and portable package include the latest interface and diagnostic fixes.

## Downloads

- `DesktopTools-1.2.5-win-x64-setup.exe` — per-user installer.
- `DesktopTools-1.2.5-win-x64-portable.zip` — self-contained portable build.
- `SHA256SUMS.txt` — checksums for both downloads.

Requires Windows 11 x64. Screen recording, offline translation and image background removal require the Microsoft Visual C++ x64 Redistributable; recording and video editing also depend on Windows Media Foundation. The installer can direct you to Microsoft's official runtime download when needed. This release is unsigned, so Windows SmartScreen may display a warning.
