# DesktopTools 1.2.3

This patch fixes background updates that could fail with “installation files are still in use” after DesktopTools had exited.

- Setup now leaves the old installation folder before waiting for DesktopTools to exit, so setup itself does not keep that folder locked during replacement.
- The installer retains its bounded retry for other short-lived file locks and leaves the previous installation in place if a separate process keeps files locked.
- GitHub Actions dependencies were refreshed after review.

## Downloads

- `DesktopTools-1.2.3-win-x64-setup.exe` — recommended per-user installer.
- `DesktopTools-1.2.3-win-x64-portable.zip` — self-contained portable build.

Windows 11 x64 is required. Screen recording also requires Microsoft Visual C++ x64 Redistributable and Windows Media Foundation. These binaries are unsigned; Windows SmartScreen may prompt. Verify downloads using `SHA256SUMS.txt`.
