# DesktopTools 1.2.4

This patch fixes global shortcuts that could all stop working on a fresh installation when Windows or another application had already claimed one key combination.

- DesktopTools now activates every available shortcut independently at startup, even if one combination is unavailable.
- The Shortcuts page and first-run setup identify unavailable combinations. Close the conflicting application and select **Retry shortcuts**, or choose different keys.
- Added a read-only [shortcut diagnostic script](https://github.com/vg2222/DesktopTools/blob/v1.2.4/scripts/diagnose-shortcuts.ps1) for checking enabled combinations after quitting DesktopTools from the tray.

## Downloads

- `DesktopTools-1.2.4-win-x64-setup.exe` — recommended per-user installer.
- `DesktopTools-1.2.4-win-x64-portable.zip` — self-contained portable build.

Windows 11 x64 is required. Screen recording also requires Microsoft Visual C++ x64 Redistributable and Windows Media Foundation. These binaries are unsigned; Windows SmartScreen may prompt. Verify downloads using `SHA256SUMS.txt`.
