# DesktopTools 1.0.0

Initial public release of DesktopTools for Windows 11 x64.

## Highlights

- Setup detects missing Visual C++ recording dependencies and offers Microsoft's official download page with a recheck action. The recorder shows dependency guidance instead of crashing on a fresh Windows installation.
- Installer maintenance presents Update, Repair and Uninstall as three icon-led choices, with clearer descriptions, keyboard focus feedback and scrollable layouts for smaller displays.
- Every tool stays available from its category and Home search; shortcut controls now lead each tool’s settings, where you can enable, disable or change the shortcut independently.
- Presentation settings return to the Presentation tools category, including in localized interfaces.
- Theme-aware dividers separate shortcut controls from feature settings and give longer settings cards clearer rows.
- Pinned screenshot menus close immediately when their window starts its dismissal animation.
- Standard app windows retain rounded corners when Windows suppresses native rounding in virtual machines; maximized windows stay square.
- Draw and annotate over desktop applications with monitor-aware pen, highlighter, shapes, text, redaction, undo and profiles.
- Capture regions, edit screenshots and images, remove backgrounds locally, generate QR codes and sample screen colors.
- Save PNG dialogs stay open when screenshot notifications expire, including when the app is hidden in the tray.
- Record a monitor, region or application window with quality targets up to 144 FPS, optional microphone/system audio and a compact recording HUD.
- Recordings retain a usable duration even when the selected screen stays visually unchanged.
- Present with a teleprompter, spotlight, laser, freeze frame, blackout, countdown, ruler, click indicators and shortcut display.
- Use local notes, file shelf, audio mixer, OCR, English/Russian translation and video trimming/cropping.
- Redesigned notes library with search, a clear writing area, automatic saving and optional floating notes. Editors share text reliably, isolate undo between notes and offer retry if saving fails.
- Audio applications use a vertical list so every volume control is reachable with normal scrolling. Refreshing sessions preserves existing controls.
- Image and video editors group settings beside a large preview, with clear import and export actions. Recording controls start at the bottom of the selected monitor, and Quick Actions no longer adds rectangular hover outlines.
- Five interface languages, first-run setup, a screen-sharing visibility guide, searchable Help and reusable feature tours.
- First-run setup leaves all tools ready to open. Optional shortcuts start disabled until chosen.
- In-app setup includes a live appearance preview and shortcut controls without a second set of tool-availability switches.
- Initial setup pages slide and fade between steps. Standard app windows use Windows transitions; transparent notifications, embedded dialogs and installer surfaces use a short scale-and-fade dismissal without a gray final flash. Reduced-motion settings and save/recording guards are respected.
- Switching tool categories now uses a quick page fade and slide. Rapid navigation restarts smoothly; reduced-motion settings show pages immediately.
- Refined graphical installer with location selection, sharp Fluent icons, smoother scrolling and animated controls.
- Audience effects stay visible in supported captures; teleprompter, countdown, stopwatch and ruler have independent hide switches.
- Recorder controls, drawing controls, selection overlays, floating notes, notifications and teleprompter start hidden from supported captures. Setup and Settings offer individual visibility choices with a capture-compatibility warning.
- Click the recorder's display preview to choose a source. Clear text-tool tabs, category breadcrumbs, distinct settings icons and image/video import prompts make navigation easier.
- Video previews update automatically after a short pause and discard outdated renders when edits change. Original media files are preserved.
- Notes placeholders align with the caret, and editor dimension fields keep text fully visible. Cropping has explicit apply/reset controls; video crop editing stays on the original frame until applied. Background comparison uses a matched before/after pair.
- Region capture freezes the desktop when selection starts by default; Settings can keep selection live. The selected image and saved pixels come from the same frame.
- Starting region, repeat-region or OCR capture from the dashboard hides DesktopTools before Windows can animate its exit, so the app does not appear translucent in the captured frame.
- Drawing controls remain active when you click another monitor or choose an inline text color. Image resize handles appear immediately, and the video Frame inspector keeps crop and rotation controls aligned.
- Freeze frame hides DesktopTools before capture and briefly shows the exit shortcut. The first close-to-tray shows a Windows notification explaining how to reopen the app.
- Image resizing preserves pixel content and DPI; crop presets reset after applying a crop; undo memory accounting handles higher-depth images; JPEG export previews reflect the selected quality.
- Profiles preserve shortcut switches, optional key bindings and individual capture preferences. Changing appearance in setup keeps it inside the main window, and page navigation cancels unfinished scrolling.
- Reset all app data now reopens DesktopTools automatically into first-run setup after deleting its managed settings, profiles and notes. Exported files outside app data remain untouched.
- Moving an installation updates its existing startup entry. Uninstall removes that entry and continues independent cleanup steps if one fails.
- GitHub updates check at startup and hourly by default, with configurable intervals and manual checking. Update availability stays in the app; notifications offer release notes, dismissal and background updating with progress and restart confirmation.
- Setup detects existing versions and offers update, repair or uninstall without downgrading. Uninstall keeps notes/settings by default or explicitly deletes only DesktopTools-managed data.
- An interrupted uninstall leaves its uninstaller in place so removal can be retried after a locked file is released.
- Notifications wait for user activity before their dismissal timer starts. Background-update failures surface as a tinted notification, sound and taskbar flash.

## Downloads

- `DesktopTools-1.0.0-win-x64-setup.exe` — recommended per-user installer.
- `DesktopTools-1.0.0-win-x64-portable.zip` — self-contained portable build.

The binaries are currently unsigned. Verify `SHA256SUMS.txt` after downloading. The graphical installer creates per-user shortcuts and an uninstall entry without requiring administrator rights. Uninstall preserves settings and notes in `%LocalAppData%\DesktopTools` by default; removing them requires an explicit choice and confirmation.

## Requirements and known limitations

- Windows 11 x64.
- Screen recording requires Microsoft Visual C++ x64 Redistributable and Windows Media Foundation.
- 144 FPS is a target; actual unique-frame throughput depends on the source, encoder and hardware.
- Real mixed-DPI 150/200%, hour-long audio recording and Discord/Teams viewer behavior still require broader hardware testing.
- Capture exclusion and sharing-only blackout depend on the capture method used by the viewer application.
